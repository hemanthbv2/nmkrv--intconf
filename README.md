## 🎨 Visual Design & Aesthetics

- **Brochure Theme Replica:** High-contrast Cosmic Midnight Navy (`#040814`, `#071024`, `#0a1430`) combined with Radiant 3D Gold typography and Sustainability Cyan-to-Emerald leaf accents.
- **Unified Navigation Console:** A two-row glassmorphic console (7 primary links on top, 3 secondary links centered below) equipped with mini-icons, hairline gradient dividers, and active gold glow pills.
- **Mobile Responsive Drawer:** Slide-out drawer with zero horizontal overflow (`scrollWidth === clientWidth`) across all viewports from 375px mobile to 4K ultra-wide displays.
- **Glassmorphism & Micro-Interactions:** Modern backdrop blur filters, glowing borders, smooth card hover states, and live IST countdown timer.

## 🚀 Getting Started Locally

No complex dependencies or build tools required — runs as a pure static web application.

```bash
# Clone the repository
git clone https://github.com/hemanthbv2/nmkrv--intconf.git

# Navigate to the folder
cd nmkrv--intconf

# Serve locally using any static web server (e.g. Python)
python -m http.server 8000

# Open in browser
# http://localhost:8000/index.html
```
